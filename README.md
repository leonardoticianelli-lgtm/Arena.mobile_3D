# Arena.mobile_3D
# 3D Mobile Arena Game

Jogo de ação 3D em arena otimizado para navegadores mobile (Android/iOS), desenvolvido com **Three.js** e **HTML5**.

## 🚀 Como Jogar no GitHub Pages

1. Faça o fork ou clone este repositório para a sua conta no GitHub.
2. No seu repositório no GitHub, acesse **Settings** > **Pages**.
3. Em **Source**, selecione a branch `main` (ou `master`) e salve.
4. O GitHub gerará o link direto do seu jogo online (ex: `https://seu-usuario.github.io/nome-do-repositorio/`).

## 🎮 Controles Mobile

- **Joystick Esquerdo**: Movimentação 360° do personagem.
- **Botão ATIRAR**: Realiza disparos ou ataques corporais.
- **Seletor de Armas**: Alterne em tempo real entre Faca, Pistola, MP40, AK47, AWM e Bazuca.
- **Seletor de Mapas**: Troque instantaneamente entre Fábrica Abandonada, Deserto e Cidade Industrial.

## ⚡ Otimizações Aplicadas

- Iluminação procedural com Direct Light e Shadow Mapping leve.
- Modelos 3D Low-Poly construídos via código (sem dependência de assets pesados em rede 3G/4G).
- Gerenciamento dinâmico de projéteis e destruição de instâncias.
